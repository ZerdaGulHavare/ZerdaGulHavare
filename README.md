### About Me

I design and develop **chip-based AI accelerators**, working on hardware architectures that bring machine learning workloads closer to silicon. This work is part of my ongoing involvement in **Teknofest**, where I focus on the hardware side of AI systems — from architecture design to implementation and testing.

Alongside hardware work, I build software across the full stack:
- **Mobile** — full-stack mobile application development, from UI to backend integration
- **Web** — frontend development, building responsive and functional interfaces

I enjoy sitting at the intersection of hardware and software, where chip-level design decisions meet the applications that run on top of them.
